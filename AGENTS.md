# ORBITA development

- Keep existing user changes and do not publish without permission.
- Before handing off any change, run `node tools/check-orbita.mjs` and check the edited files with `git diff --check`.
- For changes to the atlas or its controls, check the actual browser view at desktop, 390×844 and 320×640 when access is available. Exercise the affected feature and adjacent workflows. For camera, appearance or depth changes, include extreme zoom in and out on the Sun, all eight planets, a dwarf planet and its moon, a major and a small moon, and Voyager 2 in both viewing scales. Check rings, atmosphere and cloud layers where present, orbit visibility, switching objects, time controls, and return from Voyager to the atlas.
- Record attempted checks, observations and any blocked browser or device checks. Do not report visual results based on computed tests alone.
