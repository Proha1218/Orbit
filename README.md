# ОРБИТА

Интерактивный атлас Солнечной системы. В нём можно осмотреть планеты и карликовые планеты, изучить каталоги спутников и пояса, изменить масштаб и время, а также открыть модели и траектории Voyager 2 и МКС.

## Скачать и запустить

Скачайте ZIP через **Code → Download ZIP** на GitHub и распакуйте его целиком. Для тестовой версии alt-3 используйте локальную папку этой ветки.

1. В Windows дважды нажмите **START.bat** в распакованной папке.
2. Дождитесь открытия браузера. Если он не открылся, скопируйте локальный адрес из окна запуска.
3. Для остановки сервера нажмите **Ctrl+C** в этом окне.

Понадобится современный браузер с WebGL 2 и Node.js либо Python 3.8+. Скрипт использует установленный Node.js, затем пробует Python. Установщики доступны на сайтах [Node.js](https://nodejs.org/) и [Python](https://www.python.org/). Для запуска серверу достаточно адреса `127.0.0.1`. Если порт 4173 занят, START.bat подберёт свободный порт.

Можно запустить сервер вручную из корня проекта и открыть адрес из консоли.

```text
node server.mjs
python server.py
```

По умолчанию адрес — [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Переменная окружения `ORBITA_PORT` задаёт другой порт. Для работы модулей и научных данных открывайте адрес сервера. При открытии `dist/index.html` напрямую атлас показывает инструкцию запуска.

Графические ресурсы и архивные эфемериды хранятся локально. Интернет нужен для перехода к внешним источникам и ручного обновления орбиты МКС. После сбоя запуска можно повторить загрузку и скопировать диагностику с экрана.

## Графика

Профиль выбирается в меню **Графика** и сохраняется для этого браузера.

| Профиль | Предел DPR | Бюджет пикселей | Частицы в поясах |
| --- | ---: | ---: | ---: |
| Авто | Адаптивно | Адаптивно | 35–100% |
| Низкие | 0,75 | 1,0 млн | 35% |
| Средние | 1 | 2,3 млн | 65% |
| Высокие | 1,5 | 5,0 млн | 100% |
| Ультра | 2 | Предел устройства | 100% |

Авто отслеживает время кадра и меняет качество ступенями. Профили управляют разрешением рендеринга и визуальной плотностью поясов. Научные расчёты используют общие координаты и шкалы. Переключатель **Показать показатели** включает временную панель с FPS, пиковым временем кадра, командами отрисовки и ресурсами рендера. Значение JS heap доступно только в браузерах, которые предоставляют этот показатель.

## Источники и ограничения

- Архив Voyager 2 использует [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) и [NAIF SPICE](https://naif.jpl.nasa.gov/pub/naif/VOYAGER/kernels/spk/). Окна покрытия и приближения описаны в [журнале реконструкции](FLIGHT_RECONSTRUCTION_PROGRESS.md).
- Модель станции и сведения об орбитальном режиме описаны в [журнале МКС](ISS_PROGRESS.md). Источники фотографий и моделей указаны в карточках и в [документации Voyager 2](SPACECRAFT.md). Для материалов NASA действуют [правила NASA по использованию изображений и медиа](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- Лицензии библиотек включены в дистрибутив. [Three.js MIT](dist/vendor/THREE-LICENSE.txt) · [Draco](dist/vendor/draco/LICENSE). В атласе отдельно атрибутированы текстуры [Solar System Scope](https://www.solarsystemscope.com/textures/).
- Для модели МКС может понадобиться больше времени и памяти. Состояние производительности, сравнительные замеры и оставшиеся проверки описаны в [журнале оптимизации](PERFORMANCE_PROGRESS.md).

Левая панель использует дерево. Стрелка раскрывает спутники у планеты или карликовой планеты, а название открывает объект. Несколько веток можно держать раскрытыми одновременно.
